# Install the terminal profile

Upload these files to the root of `rajureddi/rajureddi`:

- README.md
- profile.toml
- projects.txt
- assets/terminal.svg
- assets/terminal-mobile.svg

Keep the assets folder and filenames exactly as provided. Commit the changes and refresh your profile. The graphic embeds a restrained terminal window; it is a visual representation, not an interactive shell. Its displayed profile data comes from the included files.

The cursor is the only animated element. Reduced-motion preferences disable it. The mobile illustration uses larger text in a stacked layout. The README's identity, projects, technologies, and contact links remain readable without images.

No external image services, credentials, workflows, or JavaScript are required. The diagrams use SVG and the README uses GitHub-supported picture markup and a disclosure. Existing assets from older designs can remain; this README does not reference them.

This is a local package. Nothing has been published to GitHub by the assistant.
